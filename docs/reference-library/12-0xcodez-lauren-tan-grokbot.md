## Summary

The November post is a promo for a long Grok Bot masterclass, built around a quote in which Tan describes agents merging their own pull requests. Without the video we cannot fairly characterise Tan's caveats, if any. The quote, as printed, is an **anti-pattern** for HyperSoftwareFactory.

The August article (fully read) is a tutorial for personal Grok Bot agents, not a software factory: write a job-title charter with **never-without-asking** lines; use **reversibility** as the approval line (draft / file / tag can proceed; send / spend / publish / delete / sign-up wait); prefer specialists over one generalist; review weekly by asking the bots then spot-checking by hand.
